Real trading setup

Algo Start controls real trading after the one-time Oracle broker check and live setup are complete. Setup keeps Algo Off.

  1. Preview the exact test. Choose one option contract and one lot, with explicit trigger and buy/sell limit prices. The purchase debit must be within ₹1,000. Preview sends no orders.
  2. Run the broker check yourself. Confirm the preview's plan hash before submitting the test GTT. The separate owner tool records the real parent, its generated order and its fill. Missing linkage stays unverified.
  3. Close and confirm the test. Confirm the exact test's sell limit. The tool verifies the close, flat positions and inactive protection. It cannot adopt or close your other trades.
  4. Prepare live mode. Review the evidence digest and run the owner arm command. It rechecks the installed release, reruns tests, backs up the journal and prepares the live runtime with Algo Off.
  5. Choose Normal theta spread, then Algo Start. Oracle checks manual positions, margin, current data and a qualifying trend after 14:00 JST. It buys the hedge first, verifies its fill, then sells and verifies protection. Research does not trade.

The broker check can create a real one-lot long option and incur charges. A limit order may remain unfilled. The tool never chooses a contract or changes your price to force a fill.

Owner setup commands and recovery guide

After setup, use the desktop app normally. Algo Off prevents further engine orders; already armed broker instructions can still trigger.
